Five Primitives — everything composes from these

🔗

O(1)
🔍
Search
Find nearest vectors via sqlite-vec (brute-force scan)
O(N)
🚶
Walk
Follow edges from seeds via bounded BFS
O(K)
🍂
Decay
Reduce fitness over time, fade unused nodes
O(N)
Emergent Behaviors — compositions of primitives
Retrieval
search + walk
Find seeds, traverse the graph, return connected context
Novelty Gate
search
Nearest neighbor too close? Reject the duplicate
Cross-Linking
search + connect
Find similar nodes across domains, create edges
Deduplication
search + decay
Find near-identical nodes, decay the duplicate
Consolidation
decay + connect
Weak nodes die, orphan edges redirect to survivors
Forgetting
decay
